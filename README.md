# IMO Workbench

Статический сайт для подготовки к Международной математической олимпиаде: банк реальных задач IMO
1959–2025 с подсказками и разборами, тренировочные туры по регламенту олимпиады, библиотека техник
и учёт прогресса по семибалльной шкале.

Открывается двойным кликом по `index.html` — ни сборки, ни сервера, ни зависимостей из сети не нужно.

## Что внутри

**Задачи** — 82 задачи, отобранные по всем годам и разделам (A — алгебра, C — комбинаторика,
G — геометрия, N — теория чисел). Фильтры по разделу, по месту в наборе (1·4 — разогрев, 2·5 — средняя,
3·6 — трудная), по статусу и полнотекстовый поиск. В карточке задачи: формулировка, таймер,
2–3 подсказки, раскрываемые по одной, ответ, разбор, самооценка 0–7 и личные заметки.

**Тренировка** — генератор тура по структуре настоящего дня олимпиады: три задачи (по одной каждого
уровня), 4 часа 30 минут, максимум 21 балл. Есть короткий вариант на 1:30. Приоритет отдаётся задачам,
которые вы ещё не решили. История туров сохраняется.

**Арсенал** — 38 приёмов: что утверждает техника, по каким признакам её узнать, где обычно теряют
баллы и на каких задачах банка она отрабатывается (ссылки ведут прямо в задачу).

**Прогресс** — набранные баллы по разделам и по уровням сложности, распределение оценок, очередь
повторения (всё с баллом ≤ 3), время за доской, ориентир по медальным порогам, экспорт и импорт данных.

Горячие клавиши: `/` поиск, `J`/`K` вперёд-назад, `H` следующая подсказка, `S` разбор, `T` таймер,
`R` случайная задача, `0`–`7` поставить балл.

## Честно о данных

* Формулировки **переведены на русский и набраны вручную** по памяти составителя банка. Они близки к
  оригиналу, но это не официальный текст. В карточке каждой задачи есть ссылки на
  [imo-official.org](https://www.imo-official.org/problems.aspx) и на вики AoPS — сверяйтесь с ними,
  прежде чем считать условие точным. Задачи, где уверенность в формулировке ниже (IMO 2025),
  помечены плашкой «сверьте формулировку».
* 20 разборов из 82 — **наброски**: ключевые идеи и схема без полного оформления. Такие помечены
  плашкой «разбор — набросок» и предупреждением в начале разбора. Остальные 62 доведены до конца.
* Ответы к задачам 1960/1, 1981/3, 2006/3, 2011/1, 2015/2, 2019/4, 2022/5, 2023/1, 2025/4 дополнительно
  проверены перебором (`tools/`), для 2001/6 перебором проверено ключевое тождество.
* Шкала 0–7 — настоящая шкала IMO (42 балла за два дня), но рубрика в интерфейсе **ваша собственная**:
  официальные схемы оценивания индивидуальны для каждой задачи.
* Медальные пороги в разделе «Прогресс» — усреднённый ориентир; реальные меняются каждый год.

## Структура

```
index.html              страница целиком
assets/app.css          стили (светлая и тёмная темы)
assets/app.js           вся логика: фильтры, таймеры, туры, прогресс
assets/vendor/katex/    KaTeX 0.16.9 (MIT), подключён локально — работает офлайн
data/problems-1..5.js   банк задач по эпохам
data/techniques.js      арсенал приёмов
tools/validate.cjs      проверка данных: разбор всех формул, ссылки, обязательные поля
tools/build-artifact.cjs сборка одного самодостаточного HTML
```

## Разработка

```bash
node tools/validate.cjs        # проверяет 4000+ формул через KaTeX и целостность данных
node tools/build-artifact.cjs  # собирает dist/imo-workbench.html одним файлом
python3 -m http.server 8000    # локальный просмотр
```

Прогресс хранится в `localStorage` этого браузера: он не уходит на сервер, но и не синхронизируется
между устройствами. Переносится через «Скопировать прогресс» / «Вставить прогресс».

### Как добавить задачу

Допишите объект в подходящий `data/problems-*.js` и запустите `node tools/validate.cjs`:

```js
{
  id: "2016-1", year: 2016, num: 1, topic: "G", tier: 1,
  title: "Короткое название",
  statement: String.raw`Текст с формулами $a^2+b^2$ и выключными $$\int_0^1 f$$`,
  answer: String.raw`…`,            // необязательно
  hints: [String.raw`…`, String.raw`…`],
  solution: String.raw`*Шаг 1.* …`, // *курсив* — подзаголовок шага
  tags: ["техника", "идея"],
  partial: true,                     // если разбор — набросок
  verify: true                       // если формулировку стоит сверить
}
```

Все текстовые поля пишутся через `String.raw`, иначе `\frac` превратится в управляющий символ.
